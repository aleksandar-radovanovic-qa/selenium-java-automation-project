# Selenium Java Automation Project

Automated end-to-end UI test suite for [biomarket.rs](https://www.biomarket.rs/), built as a final exam project for **Code by Comtrade QA Academy**.

## 🧪 Test Cases

| # | Test Name | Priority |
|---|-----------|----------|
| 1 | Validate login with empty username | Medium |
| 2 | Validate login with empty password | Medium |
| 3 | Validate login with invalid username and password | High |
| 4 | Validate login with valid username and password | High |
| 5 | Validate logout of an already logged in user | High |
| 6 | Validate removing item from a shopping cart | Medium |
| 7 | Validate completing a purchase of an item | High |

## 🛠️ Tech Stack

- **Language:** Java
- **Framework:** Selenium WebDriver
- **Build Tool:** Maven
- **Browser:** Chrome
- **OS:** Windows 11

## 🚀 How to Run

1. Clone the repository
```bash
git clone https://github.com/aleksandar-radovanovic-qa/selenium-java-automation-project.git
```
2. Open the project in IntelliJ IDEA
3. Run tests via Maven:
```bash
mvn test
```
